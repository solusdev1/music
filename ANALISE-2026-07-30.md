## 3. Princípio de Honestidade de Duração

### 3.1 O Problema

Playlist de **25:48** anunciava **"1 Hour"** no título.
- Usuário espera 60 min → sente enganado nos primeiros 30s
- Engano quebra retenção (retention) imediatamente
- Impacta métricas de session watch time e CTR futuro

### 3.2 Solução Implementada

Função `_rotulo_duracao(total_sec, idioma="pt")` em `core/brief.py`:
```python
if m >= 55:                    # 55+ minutos
    h = round(total_sec / 3600)
    return f"{h} Hora{'s' if h > 1 else ''}" if idioma == "pt" else f"{h} Hour{'s' if h > 1 else ''}"
dez = max(10, (m // 10) * 10)  # Arredonda para 10, 20, 30, 40, 50
return f"{dez} Minutos" if idioma == "pt" else f"{dez} Minutes"
```

**Exemplos:**
- 315s (5:15) → "10 Minutes"
- 1585s (26:25) → "20 Minutes" ✅ (não "1 Hour" — correto)
- 3661s (61:01) → "1 Hour" ✅

**Benefício:** Sinceridade restaura confiança em playlists futuras. Mesmo que playlist seja mais curta, usuário sabe exatamente o que vai receber.

### 3.3 Integração com Títulos

Fórmulas de título agora incluem `{DURACAO}` placeholder, substituído dinamicamente:
```
"{GANCHO} 🙏 | {DURACAO} de Country Blues Gospel Para {BENEFICIO}"
```
Após geração da playlist:
```
"DEUS CONHECE SUA DOR 🙏 | 20 Minutos de Country Blues Gospel Para Acalmar o Coração"
```

## 4. Geração de Conteúdo Ciente de Idioma

### 4.1 Problema Resolvido

Canais em inglês (country_blues_en.json, southern_grace_roads.json) recebiam temas em português:
```
"Salmo 23 — o Senhor é meu pastor"  ❌
```

Saída esperada:
```
"Psalm 23 — the Lord is my shepherd"  ✅
```

### 4.2 Solução Arquitetural

#### a) `core/quality.py` — Stopwords por idioma
Adicionado `_STOPWORDS_EN`, `_STOPWORDS_ES`, e roteamento automático:
```python
_STOPWORDS_PT = {"de", "a", "que", "e", "é", "em", ...}
_STOPWORDS_EN = {"the", "of", "to", "and", "a", "in", ...}
_STOPWORDS_ES = {"de", "la", "que", "el", "es", "y", ...}

def _stopwords(idioma=None):
    if not idioma:
        return _STOPWORDS_PT
    lang = str(idioma)[:2].lower()
    return _BANCOS.get(lang, _STOPWORDS_PT)
```

**Impacto:** Palavras como "more", "that", "still" (stopwords EN) não mais aparecem como "imagens saturadas" em análise de qualidade.

#### b) `core/brief.py` — Templates de descrição por idioma
```python
DESCRICAO_PADRAO = {
    "pt": "Esta playlist foi preparada para acompanhar quem precisa descansar...",
    "en": "Made for anyone who needs to set the weight down for a while...",
    "es": "Preparada para acompañar a quien necesita descansar...",
}
```

Seleção automática:
```python
def descricao(cfg, tema, chapters, titulo):
    tpl = cfg.get("descricao_template") or DESCRICAO_PADRAO.get(
        str(cfg.get("idioma", "pt"))[:2].lower(), DESCRICAO_PADRAO["pt"])
    return tpl.format(...)
```

#### c) `niches/` — Temas em idioma nativo
- **country_blues_fe.json, estrada_da_fe.json**: Temas portugueses ("Salmo 23 — o Senhor é meu pastor")
- **country_blues_en.json, southern_grace_roads.json**: Temas em inglês ("Psalm 23 — the Lord is my shepherd")
- **camino_de_la_fe.json**: Temas em espanhol ("Salmo 23 — el Señor es mi pastor")

### 4.3 Regressões Validadas

✅ Português detecta "deus" como protegida (não saturada)  
✅ Inglês NÃO marca "more/that/still" como saturadas  
✅ Espanhol roteia para stopwords espanhóis  
✅ Tema do dia gerado em idioma nativo (não tradução do português)  
✅ Descrição da playlist em idioma nativo

## 6. Melhorias Sistêmicas Implementadas

### 6.1 Playlist Rebuild Logic (`core/playlist.py`, `core/catalog.py`)

**Problema original:** Após `build() → save()`, as faixas entravam em cooldown (21 dias). Tentar remontar a mesma playlist falhava com "nenhuma faixa elegível".

**Solução:** 
- `eligible_tracks()` ganhou parâmetro `ignorar_playlist=pid`
- `cmd_build_playlist()` detecta playlist existente por slug e passa seu ID
- **Apenas a remontar da mesma playlist** ignora o cooldown; playlists NOVAS respeitam cooldown normal

**Workflow habilitado:**
```bash
# Dia 1: Criar playlist com durações estimadas
python3 cli.py daily-brief --niche southern_grace_roads --com-playlist
python3 cli.py build-playlist --niche southern_grace_roads --save sgr-2026-07-30

# Dia 2: Áudio realizado no Suno, durações atualizadas
python3 cli.py set-audio --slug sgr-2026-07-30-1 --file 01.mp3 --duration 265
python3 cli.py set-audio --slug sgr-2026-07-30-2 --file 02.mp3 --duration 271
...
python3 cli.py build-playlist --niche southern_grace_roads --save sgr-2026-07-30

# Resultado: Chapters recalculados com durações REAIS, sem colisão de cooldown
```

### 6.2 Tratamento de Duração Honesta

`brief.py:make_titles()` agora aceita `total_sec` parameter e preenche `{DURACAO}` dinamicamente:
```python
titulos.append({
    "gancho": ganchos[i],
    "titulo": (formula.replace("{GANCHO}", ganchos[i])
                      .replace("{BENEFICIO}", beneficios[i % len(beneficios)])
                      .replace("{DURACAO}", _rotulo_duracao(
                          total_sec, cfg.get("idioma", "pt")))),
})
```

### 6.3 Roteamento de Idioma em Quality & Brief

- `quality.vocabulary_report()` agora aceita `idioma` parameter
- `brief.descricao()` roteia templates por `cfg["idioma"]`
- Temas carregam em idioma nativo, não traduzem português

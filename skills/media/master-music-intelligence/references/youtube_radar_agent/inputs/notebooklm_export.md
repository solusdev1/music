# NotebookLM export / fontes

Cole aqui o texto exportado/copied do NotebookLM, incluindo URLs de canais/vídeos do YouTube que você adicionou como referência.

Como usar:
1. Abra seu NotebookLM.
2. Copie a lista de fontes, notas, briefing ou resumo com os links.
3. Cole tudo neste arquivo.
4. Rode: bash run_radar.sh 5

O script vai extrair automaticamente links youtube.com e youtu.be deste texto.
